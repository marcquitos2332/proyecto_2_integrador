1. Identificación del problema

a. ¿Cuál es el problema principal que identifican?

El problema principal es la falta de conocimientos sobre tecnología, medios de pago digitales y seguridad en Internet que puede dejar a las personas adultas mayores expuestas a estafas y fraudes digitales.

b. ¿A quiénes afecta esta problemática?

Afecta principalmente a personas adultas mayores que tienen poca experiencia utilizando celulares, Internet, aplicaciones bancarias, billeteras virtuales y otros medios de pago digitales. También puede afectar a sus familiares cuando deben ayudarlos a resolver este tipo de situaciones.

c. ¿Qué situaciones de la vida cotidiana pueden estar relacionadas con este problema?

Algunas situaciones pueden ser recibir un mensaje falso de un banco, recibir una llamada de una persona que se hace pasar por un empleado bancario, ingresar a un enlace fraudulento, compartir códigos de seguridad, entregar datos de una tarjeta o realizar una transferencia a una persona desconocida.

d. ¿Por qué consideran importante abordar esta problemática?

Consideramos importante abordar esta problemática porque cada vez utilizamos más la tecnología para realizar operaciones financieras. Las personas adultas mayores necesitan contar con información clara y sencilla que les permita utilizar estas herramientas de manera segura, reconocer posibles estafas y proteger su dinero y sus datos personales.
